# Cartella Loghi - Istruzioni di Caricamento

Inserisci qui le immagini mockup ed i loghi per ciascun brand. Il sistema è configurato per leggere dinamicamente i file da queste cartelle e, in loro assenza, mostrare dei bellissimi fallback grafici.

## Struttura delle Sotto-cartelle:

1. **Sicef** -> inserisci le immagini in:
   `public/assets/loghi/sicef/`
   *Nomi consigliati*: `mockup1.webp`, `mockup2.webp`, ecc.

2. **Mapi Creazioni** -> inserisci le immagini in:
   `public/assets/loghi/mapicreazioni/`
   *Nomi consigliati*: `mockup1.webp`, `mockup2.webp`, ecc.

3. **Villa Masami** -> inserisci le immagini in:
   `public/assets/loghi/villamasami/`
   *Nomi consigliati*: `masami-1.png` a `masami-8.png` o `.webp`.

## Linee guida per le immagini:
- **Formato**: Preferibilmente `.webp` o `.png` per il massimo bilanciamento tra qualità e velocità di caricamento.
- **Rapporto d'aspetto**: `3:2` o simile per riempire perfettamente le schede del portfolio brutalista.
