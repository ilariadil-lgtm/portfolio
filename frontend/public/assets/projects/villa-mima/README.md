# Villa Mima Assets

Per caricare le immagini del progetto **Villa Mima**, inserisci all'interno di questa cartella i seguenti file in formato `.webp`:

1. `homepage.webp` - Lo screenshot o mockup principale per la hero (formato consigliato aspect ratio `3:2`).
2. `struttura.webp` - L'immagine per la sezione "03 — Il Processo / Direzione Visiva" (formato consigliato aspect ratio `3:2`).
3. Per lo slider orizzontale continuo (Visual Showcase), puoi inserire le seguenti immagini:
   - `homepage.webp`
   - `camere.webp`
   - `struttura.webp`
   - `servizi.webp`
   - `giardino.webp`
   - `piscina.webp`
   - `dettagli.webp`
   - `contatti.webp`

> **Nota**: Il codice include una gestione automatica dei fallback su immagini esistenti nel caso in cui qualcuna di queste immagini non sia presente al caricamento della pagina, garantendo così un'esperienza utente sempre eccellente e senza interruzioni visive!
